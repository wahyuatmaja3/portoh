### Peningkatan Visual (Lebih "Hidup")

#### Background Patterns
Menambahkan subtle patterns pada setiap section:

1. **Hero**: 
   - Gradient opacity ditingkatkan: `0.08` → `0.12`
   - Ditambahkan horizontal line pattern

2. **About**:
   - Gradient opacity ditingkatkan: `0.08` → `0.12`, `0.06` → `0.08`
   - Ditambahkan diagonal stripe pattern (45deg)

3. **Skills**:
   - Gradient opacity ditingkatkan: `0.06` → `0.08`, `0.05` → `0.07`
   - Ditambahkan vertical line pattern

4. **Projects**:
   - Gradient opacity ditingkatkan: `0.04` → `0.06`, `0.06` → `0.08`
   - Ditambahkan diagonal stripe pattern (-45deg)

5. **Contact**:
   - Gradient opacity ditingkatkan: `0.05` → `0.07`, `0.06` → `0.08`
   - Ditambahkan horizontal line pattern

### Hasil
- Tampilan lebih padat dan efisien
- Lebih banyak konten terlihat di viewport
- Background lebih "hidup" dengan subtle patterns
- Tetap menjaga readability dan hierarchy
- Mobile-friendly dengan spacing yang proporsional
